2. Qué datos podemos tratar

  • Datos de cuenta, como correo electrónico, identificador y preferencias, si creas una cuenta.
  • Mensajes, instrucciones, archivos e imágenes que decidas enviar para utilizar las funciones de IA.
  • Historial de conversaciones y ajustes, si la función de guardado está activada.
  • Datos técnicos básicos y registros de seguridad necesarios para mantener el servicio y prevenir abusos.
  • Mensajes que nos envíes al contactar con soporte.

No envíes datos especialmente sensibles ni información de otras personas salvo que sea necesario y tengas una base legítima para hacerlo.

3. Para qué usamos los datos

  • Prestar las funciones de chat y las herramientas que solicites.
  • Crear y gestionar tu cuenta, autenticarte y, cuando esté habilitado, guardar tus conversaciones.
  • Responder a consultas y resolver incidencias.
  • Proteger el servicio, detectar usos fraudulentos y cumplir obligaciones legales.
  • Mejorar el funcionamiento y la seguridad, evitando usar los contenidos para fines no explicados aquí.

4. Base jurídica

Según el caso, el tratamiento puede ser necesario para prestar el servicio solicitado o aplicar medidas precontractuales, para cumplir obligaciones legales, para proteger intereses legítimos relacionados con la seguridad o basarse en tu consentimiento cuando sea requerido. La base aplicable debe comprobarse para cada función activa y explicarse de forma específica si corresponde.

5. Proveedores y destinatarios

Para operar la web pueden intervenir proveedores de alojamiento, autenticación, almacenamiento, entrega de correo o procesamiento de IA. Solo deben mencionarse como proveedores activos aquellos que realmente estén integrados en producción. Antes de publicar, completa esta sección con sus nombres, funciones, ubicación y enlaces a sus políticas; indica también si el contenido que envías se remite a un proveedor de IA externo.

No se venden tus datos personales. Los datos solo se comunicarán cuando sea necesario para prestar el servicio, exista una obligación legal o hayas autorizado la comunicación.

6. Transferencias internacionales

Si algún proveedor trata datos fuera del Espacio Económico Europeo, deben identificarse los países y las garantías aplicables, cuando corresponda. Verifica las regiones configuradas en el alojamiento, la base de datos y los servicios de IA antes de publicar esta política.

7. Conservación

Conservaremos los datos solo durante el tiempo necesario para la finalidad para la que se recogieron, mientras mantengas la cuenta o durante los plazos exigidos por ley. Los historiales guardados se conservarán conforme a los controles que ofrezca la aplicación y a la política de borrado que realmente esté implementada.

8. Tus derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento y, cuando proceda, portabilidad, escribiendo a contacto@pnova-ai.es. Podemos pedir información razonable para verificar tu identidad. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

9. Seguridad y menores

Aplicamos medidas técnicas y organizativas proporcionadas al servicio, aunque ningún sistema puede garantizar seguridad absoluta. Si detectas un problema, contacta con nosotros. Si el servicio no está diseñado para menores de una determinada edad, esa restricción debe indicarse expresamente en las condiciones y aplicarse en la práctica.

10. Cambios en esta política

Podemos actualizar esta política cuando cambien las funciones, proveedores o requisitos legales. Publicaremos la versión vigente en esta página e indicaremos la fecha de actualización.

Si tienes dudas sobre esta página, contacta con contacto@pnova-ai.es.
